# Contenu du site

Ce dépôt contient le contenu du site : textes, images et CV. Tous les exemples sont fictifs.

## Modifier le contenu

1. Va sur <https://app.pagescms.org> et connecte-toi avec GitHub.
2. Sélectionne ce dépôt, puis ouvre **Contenu du site**.
3. Modifie les champs et clique sur **Enregistrer**.

Les images et le CV se changent dans l'onglet **Médias**.

⚠️ Ce dépôt est public : n'y écris aucune information privée.
